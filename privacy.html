Mutelog Uploader 개인정보처리방침

시행일: 2026-11-23

1. 수집하는 정보

Mutelog Uploader는 Google 로그인 시 YouTube 업로드 권한(youtube.upload)만 요청합니다. 이름, 이메일, 연락처 등 개인정보는 수집하지 않습니다.

2. 이용 목적

발급된 인증 토큰은 채널 운영자 본인의 YouTube 채널에 영상을 업로드하는 용도로만 사용합니다.

3. 보관 및 공유

인증 토큰은 운영자 본인의 컴퓨터에만 저장되며, 외부 서버로 전송하거나 제3자와 공유하지 않습니다.

4. 권한 철회

언제든지 Google 계정 권한 페이지에서 접근 권한을 삭제할 수 있습니다.

5. Google API 정책

Google API로부터 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요구사항 포함)을 따릅니다. YouTube API 이용 시 YouTube 서비스 약관과 Google 개인정보처리방침이 함께 적용됩니다.
